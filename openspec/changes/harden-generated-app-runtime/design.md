## Context

生成产物是无依赖的 HTML、CSS 和 JavaScript。服务端可以安全编译检查 JavaScript，但不应执行生成脚本。DOM 和 Canvas 运行时错误只能在受限 iframe 中观察。

## Decisions

1. 生成路由在返回任意产物前用 `node:vm` 的 `Script` 仅编译不执行，覆盖所有模型。
2. 千问适配器在首次脚本语法无效时只进行一次修复，避免无限请求和不可控费用。
3. iframe 只传递错误名称和受限长度的消息，不传递堆栈或宿主数据。
4. 运行时错误不自动消耗模型额度。用户点击「修复应用」后，工作台进入继续修改流程并预填错误摘要。

## Risks

- 语法正确不代表行为正确；通过 iframe 报错和人工触发修复补足。
- 修复请求可能多消耗一次 Token；限制为只有语法错误时一次。
