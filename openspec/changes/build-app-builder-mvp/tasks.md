# Tasks

## 1. 搭建工作台与生成接口

- [x] 1.1 初始化 React、TypeScript 和 Vite，建立同源开发入口。用 `npm run dev` 打开工作台，并用 `npm run build` 验证生产构建。
- [x] 1.2 定义生成接口的输入、输出和错误结构。先写针对空输入、合法响应、无效模型结果和超时的测试，再实现 `POST /api/generate`，验证这些分支返回预期结果。
- [ ] 1.3 接入 Responses API，配置服务端密钥、模型和超时。在 README 记录运行方法及环境变量，并用真实模型在本地生成一次可运行的网页。
- [x] 1.4 接入可选的本地 Ollama，验证无需云端密钥即可根据自然语言生成并操作应用。

## 2. 完成生成、预览与恢复

- [x] 2.1 实现需求输入、生成状态、结果展示和失败重试。用浏览器测试验证重复提交只发出一次请求，失败后仍可编辑并重试。
- [x] 2.2 将生成结果接入隔离预览，显示脚本运行错误。用浏览器测试验证预览按钮能改变页面状态，且预览脚本无法访问宿主文档或项目存储。
- [x] 2.3 保存并恢复最近成功的项目。用浏览器测试验证刷新无需重新生成，后续失败保留旧结果，存储不可用时预览可用且有明确提示。
- [x] 2.4 提供标明来源的待办和记账内置示例。用浏览器测试验证试用期间不调用生成接口、不覆盖需求或已保存的项目。

## 3. 部署与验收

- [ ] 3.1 部署工作台和生成接口，设置模型凭据与请求限额。用无痕窗口确认无需登录，且限制触发时返回可理解的提示。
