# Proposal

## Why

用户需要从自然语言需求快速得到一个可操作的网页原型，并能在刷新后回到上一次生成的结果。第一版优先完成评审可独立体验的生成、预览和恢复流程。

## What Changes

- 增加免登录的生成工作台，提供需求输入、生成进度、交互预览和失败重试。
- 接入真实模型，根据需求生成单页 HTML、CSS 和 JavaScript，在受限的浏览器预览中运行。
- 在同一浏览器保存最近成功生成的项目，刷新后恢复需求和预览。
- 提供可独立试用的内置待办和记账示例，在模型不可用时演示预览交互。
- 提供一个无需登录即可测试的在线部署地址，并以待办清单、支出记录两种不同应用验证生成能力。
- 对话式修改留待核心流程验收后再评估。账号、跨设备同步、任意依赖安装和生成应用的独立发布超出本次范围。

## Capabilities

### New Capabilities

- `app-generation` — 根据自然语言生成网页应用，并反馈进度和失败。
- `interactive-preview` — 在工作台内隔离运行生成的网页并支持真实操作。
- `project-recovery` — 保存和恢复同一浏览器中最近成功生成的项目。

### Modified Capabilities

## Impact

- 新增网页工作台、生成 API、浏览器持久化和部署配置。
- 服务端需要模型凭据和可用的模型额度，评审使用工作台无需自行配置密钥。
