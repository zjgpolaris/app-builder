# Spec Delta

## Purpose

让用户直接描述要做的应用和需要支持的操作，获得可在浏览器运行的网页。生成过程提供清楚的状态反馈，失败时允许用户沿用原需求重试。

## ADDED Requirements

### Requirement: 从自然语言生成应用

工作台 SHALL 允许用户无需登录即可提交非空需求，由服务端调用实际模型生成网页应用。

#### Scenario: 从空白工作台生成待办清单

- **WHEN** 用户提交「生成一个可以新增任务并勾选完成的待办清单」
- **THEN** 工作台显示生成中状态，成功后展示可操作的待办应用

#### Scenario: 根据不同需求生成不同功能

- **WHEN** 用户提交「生成一个可以录入支出名称和金额、并显示总额的记账页」
- **THEN** 工作台展示具有支出录入和总额计算功能的应用

#### Scenario: 拒绝空输入

- **WHEN** 用户尝试提交空白需求
- **THEN** 工作台提示输入需求，且不发起生成请求

### Requirement: 生成失败后可以重试

工作台 SHALL 在请求超时、服务不可用或模型结果无法使用时显示可理解的错误，并保留输入以便重试。

#### Scenario: 服务暂时不可用

- **WHEN** 用户提交需求后生成服务返回错误
- **THEN** 工作台结束加载并显示错误和重试入口
- **AND** 用户可直接重试该需求或修改后重新提交

#### Scenario: 生成中重复提交

- **WHEN** 当前生成尚未完成，用户再次触发提交
- **THEN** 工作台不发出第二个生成请求
